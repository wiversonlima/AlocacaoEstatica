# AlocacaoEstatica Repository

This repository contains a Flutter Product Registration application with local JSON storage.

## 📱 Flutter App

The main application is located in the `flutter_app/` directory.

### Quick Start

```bash
cd flutter_app
flutter pub get
flutter run
```

### Features

✅ **Product Model** - id_subproduto, id_produto, titulo fields  
✅ **Local JSON Storage** - Persistent data storage  
✅ **CRUD Operations** - Create, Read, Update, Delete  
✅ **Form Validation** - Input validation with error messages  
✅ **Material Design UI** - Modern, clean interface  
✅ **Success/Error Messages** - User-friendly feedback
